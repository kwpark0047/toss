## 재개 조건과 통과 기준

연속 테스트 가능한 기존 Live 실기기 이용권 또는 사용자 소유 실제 기기가 필요하다. 새 구매는 진행하지 않았다. [연결 안내서](../REMOTE_SESSION_GUIDE.md)의 절차에 따라 iPhone은 홈 화면 PWA를 먼저 설치하고 그 앱 안에서 주문·동의한다. 원격 URL 입력 경로를 먼저 확인한 다음 테스트를 시작한다.

기기별로 주문·금액 → 서버 구독 → 고객 페이지 종료 → 준비 완료 변경 → OS 알림 수신 → 실제 알림 탭 → 같은 주문 준비 완료 화면을 연결해서 저장해야 PASS로 변경한다. 홈 이동과 앱 전환기 강제 종료는 별도 기록한다. 네이버·유튜브 버튼의 실제 기기 이동도 아직 확인하지 못했다.
