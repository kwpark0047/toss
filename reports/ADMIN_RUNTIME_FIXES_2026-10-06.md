# 관리자 화면 및 API 오류 수정

정산·법적 정보·매장 환경설정 등에서 선언되지 않은 아이콘 참조와 컴포넌트/이름 문자열 혼용을 수정했습니다. SVG 크기 문자열 및 공통 Icon을 가리는 지역 변수도 수정했습니다.

동적 가격의 목록을 실제 API data/items envelope에서 배열로 추출하고 실패 안내·재조회 및 React Query 갱신을 적용했습니다. 캠페인의 빈 상태 아이콘과 액션은 JSX로 전달하며 트리거별 아이콘의 타입을 통일했습니다. 법적 정보는 API 응답에서 실제 데이터를 읽습니다.

주문 통계·상세 통계·상품 목록 등의 validateParams에 중첩 객체를 넘기는 오류를 수정하고 필수 storeId 스키마를 적용했습니다. 커뮤니티 피드는 business_type을 store_business_info에서 읽습니다. 사업자·법적 정보·영업시간의 조회/저장은 분리된 도메인 테이블을 이용하며 기존 API 응답 형태는 유지합니다. DB 마이그레이션을 추가로 실행하지 않았습니다.

회귀 검사: SaaS 31개, 관련 사업자·커뮤니티·권한·법적 정보 56개, 관리자 모듈·목록 응답 11개 통과. 실제 Chromium으로 여섯 관리자 화면과 정산 명세서·가격 탭·캠페인 빈 상태·결제수단을 검사합니다. 이 브라우저 검사는 운영 계정/데이터가 아닌 격리 fixture를 사용합니다.

운영 DB SELECT로 사업자 정보와 커뮤니티 피드 쿼리 호환성을 확인했습니다. 정상 로그인 계정으로 보호된 운영 API를 직접 조회하는 검증은 수행하지 않았습니다. CI에 관리자 브라우저 검사 및 아이콘 metadata 참조 검사도 추가했습니다.
