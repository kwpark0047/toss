# 고객 채팅창 한글 문구 수정

고객 채팅창에서 `chat.manager_title` 등의 키가 노출됐다. 컴포넌트에서 사용하는 chat 번역 리소스가 한국어를 포함한 기존 번역 파일에 없었던 것이 원인이다. 한국어 리소스에 다음 다섯 문구를 추가했다. 기존 fallbackLng=ko 설정을 통해 다른 언어에서도 키 대신 한글을 표시한다.

| 키 | 한국어 |
| --- | --- |
| chat.manager_title | 매장 문의 |
| chat.live_support | 실시간 상담 |
| chat.ask_manager | 매장에 궁금한 점을 물어보세요 |
| chat.chat_examples | 메뉴, 주문, 이용 방법을 문의해 주세요. |
| chat.input_placeholder | 메시지를 입력해 주세요 |

실제 i18next 해석으로 수정 전 키 노출을 재현하고 수정 후 5개 문구와 한국어 fallback을 확인했다. 프론트엔드 빌드도 통과했다.

빌드된 고객 화면과 격리 테스트 API에서 390×844, 1280×900 화면의 채팅창을 열어 제목·안내·입력창과 번역 키 미노출을 확인했다. 외부 Google Fonts만 차단해 시스템 폰트로 렌더링했다. 채팅방 생성은 테스트 게이트웨이에서 차단되며 메시지는 보내지 않았다. 이번 결과는 화면 문구 검증이며 실제 휴대폰 푸시·채팅 전송 검증이 아니다.
