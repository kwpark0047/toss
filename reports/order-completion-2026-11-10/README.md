# 주문 완료 1차 고도화 — 2026-11-10

- 실제 고객 메뉴 `MenuPage`의 주문/결제 후 확인 화면 및 토스 복귀 `PaymentSuccess`에 공통 확인 카드 적용.
- 레거시 고객 Menu/PaymentSheet 완료 화면도 공통 카드 사용.
- 메뉴·수량·옵션·할인·배달비·최종 결제금액·결제수단 표시. 현금/이체는 완료와 대기를 구분.
- 가벼운 SVG 감사 이미지, 매장찾기·네이버·유튜브 선택 제공.
- 매장찾기 `/search`에 최근 주문 버튼을 표시하고 기존 OrderStatusModal로 연결. 주문 조회 capability는 URL이 아닌 세션에 유지.
- 결제 완료 재방문은 표시용 세션 캐시로 복원하며 승인 재호출 방지. 최초 복귀 시 준비 세션과 결제 ID·주문번호·금액 일치 확인.
- 앱 설치/푸시 안내는 주문 확인·이동 버튼 아래에 유지.

재현: `frontend`에서 로컬 Vite 서버를 5190 포트로 실행한 후 `node scripts/verify-order-completion.cjs` 실행.

## 증거와 범위

- `results.json`: 각 너비의 자동 검증 결과.
- `payment-*.png`: 결제 완료 화면.
- `finder-*.png`: 매장찾기의 주문 확인 진입점.
- `progress-*.png`: 해당 주문 진행 화면.
- `long-order-*.png`: 긴 주문 및 다크 시스템 모드.

API와 외부 목적지 문서는 합성 응답으로 가로챘으며 운영 DB/결제 제공자에 쓰기 작업을 하지 않았다. 서버 소켓은 실행하지 않아 연결 실패 로그가 있으며, 실시간 소켓 이벤트의 운영 수신은 검증 범위에 포함되지 않는다. 기존 주문 진행 화면의 API 조회와 정기 갱신은 연결/단위 테스트로 확인했다. 배포 및 운영 실결제 검증은 수행하지 않았다.
