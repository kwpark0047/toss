# 메뉴 관리 UI/UX 개선

메뉴 추가를 기본 작업으로 두고 사진·AI·일괄 등록은 펼침 도구로 묶었습니다. 검색·카테고리·판매 상태 필터와 결과 개수를 목록 위에 배치하고 선택한 메뉴의 품절 처리·판매 재개·삭제를 제공했습니다. 필터 변경 시 선택을 해제하여 숨겨진 항목에 작업하는 실수를 줄였습니다.

목록의 큰 카드와 호버 전용 작업을 작은 행 및 항상 보이는 편집 버튼으로 바꿨습니다. 모바일에서도 카테고리 필터·편집과 메뉴 가져오기·옵션 도구를 사용할 수 있습니다. 가져오기 대화상자는 native dialog의 Escape·초점 관리 및 입력 검증을 사용합니다. 조회 실패를 빈 목록과 구분하고 이전 데이터·재시도를 제공합니다. 밝은/어두운 테마와 키보드 초점 표시를 유지합니다.

메뉴 추가의 named export lazy 로딩 오류도 수정했습니다. 상품 목록 서비스와 매장 Repository에서 비동기 캐시 조회를 기다리도록 수정했고, 메뉴 관리 및 빌더는 API envelope를 배열로 추출합니다. 빌더 조회 실패 시 재시도를 제공하고 실패 상태에서는 디자인 저장을 막습니다. Socket.IO는 WebSocket 우선·폴링 fallback을 사용하며 운영 WebSocket 전송 연결을 확인했습니다.

검증: SaaS 회귀 32개 및 기존 상품 서비스 15개 통과. Chromium 1440px 두 테마·390px 모바일에서 검색·상태 필터·선택 해제·카테고리·가져오기 Escape·조회 실패/재시도·메뉴 추가·빌더 레이아웃을 격리 API fixture로 검증합니다. 실제 사용자 비밀번호나 운영 상품 쓰기는 사용하지 않습니다. CI에 동일 브라우저 검사를 추가했습니다.
