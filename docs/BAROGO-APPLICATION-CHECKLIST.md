# 바로고 제휴 신청 진행표

확인일: 2026-11-16. 사용자 회신: 신청 정보 전체 **미정**.
현재 상태: 신청 준비 완료, 외부 문의 미발송·제휴 신청 미접수. 신청 주체와 회신 연락처가 정해진 후 접수한다.

## 신청인 확정 항목

| 항목 | 현재 값 | 사용 목적 |
| --- | --- | --- |
| 계약 사업자명, 개인/법인 구분 | 미정 | 제휴 신청 주체 |
| 사업자등록번호, 대표자, 사업장 주소 | 미정 | 사업자 확인·계약 자료 |
| 신청 담당자 이름·직책·회사 이메일·전화 | 미정 | 최초 문의 발신·회신 |
| 개발 담당자 연락처 | 미정 | 개발자 계정·기술 협의 |
| 시험 매장 수·지역 | 미정 | 파일럿 범위 |
| 시험 매장의 바로고 계약 여부·매장 정보 | 미정 | 기존 매장 매핑 협의 |
| 월 예상 주문량·희망 시험 시작일 | 미정 | 물량·일정 협의; 초기 문의에는 미정 표기 가능 |

위 사업자 항목은 신청 준비용이다. 실제 필수 서류와 제출 시점은 바로고 담당자 안내로 확정한다. 사업자등록증 사본은 담당자가 지정한 공식 접수 채널로 제출한다. 최초 담당자 연결 문의에는 우선 사업자명과 담당자 이름·회신 이메일을 확정한다.

## 직접 처리할 항목과 지원 범위

| 단계 | 신청인 직접 처리·결정 | 개발 지원 범위 |
| --- | --- | --- |
| 최초 제휴 문의 | 신청 사업자·담당자·회신 주소 확정 | 기존 문의 초안에 정보 반영, 담당 창구 연결 요청 |
| 개발자 가입 | 회사 관리 이메일 사용, 비밀번호 설정, 요구되는 이메일/본인 인증 | 가입 경로·입력 항목 안내 |
| 정책·계약 | 약관·NDA·계약 동의 또는 서명, 요금·정산·오픈 일정 결정 | 기술 조건 정리·질문 작성 |
| 시험 매장 | 이용 동의·기존 바로고 계약 확인, 시험 범위 결정 | 매장 ID 매핑 설계·검증 |
| 테스트 승인 | 실배차·과금 여부 확인 후 시험 범위 결정 | 인증·콜백 구현, 샌드박스 시험·결과 보고 |
| 운영 전환 | 비용·계약 조건 및 운영 개시 결정 | 검수 대응·배포·모니터링 |

이메일/본인 인증은 포털에서 요구되는 경우 신청인이 수행한다. 현재 실제 가입 화면에서 인증 수단까지 확인한 것은 아니다. 비밀번호·인증 코드·API Key는 채팅이나 이 파일에 남기지 않는다.

## 공식 절차와 제안할 모델

공식 순서: 영업/운영 협의·사전 체크리스트 → 개발자 가입 → 주문 제휴사 등록 → API Key·콜백 등록 → 테스트 → 운영 오픈 요청·승인. 제휴 협의와 테스트는 병행 가능하다고 안내되어 있다.

WeMarket는 **매장별 기존 계약 유지 + 상점 기반 매핑 + 배달 요청 연동(FOR_DELIVERY)**을 우선 협의안으로 제시한다. 이는 제품 요구와 공개 명세에 따른 제안이며, 바로고가 승인한 계약·요금 모델은 아니다. ACCEPTED_ORDER 방식과의 차이 및 최종 적용 방식은 담당자와 확인한다.

최초 기술 문의 후보는 고릴라 TAM `tech_poc@barogo.com`이다. 공식 가이드에 기술 문의 창구로 공개되어 있으며, 신규 제휴 영업 접수처라고 단정하지 않고 영업/운영 담당자 연결을 요청한다.

문의 제목: `[WeMarket] 고릴라 신규 주문 제휴 및 테스트 연동 담당자 연결 요청`

문의 본문은 [기존 신청 자료의 바로고 문의 초안](./DELIVERY-PARTNERSHIP-APPLICATION.md#4-바로고-문의-초안)을 사용한다. 사업자명·담당자·회신처 미정 상태로 발송하지 않는다. 물량과 일정은 미정으로 남겨 문의할 수 있다.
