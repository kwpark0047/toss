## 발견 및 수정

1. **권한 확인 중 종료 후 Provider 연결 경합:** WebSocket 종료 중 비동기 권한 확인이 완료되면 이미 종료된 세션에서도 Provider 연결이 시작될 수 있었다. 권한 확인 직후 종료 상태를 다시 확인해 연결을 막았다.
2. **느린 도구와 사용량 정산/차단 경합:** 사용량 이벤트가 도구 처리 큐 뒤에 대기해 종료 정산에서 빠지거나 예산 초과 차단이 지연될 수 있었다. 수신 즉시 사용량을 계산·기록하고 예산을 확인하도록 도구 큐에서 분리했다. 도구가 지연돼도 수신된 비용을 정산하고 초과 시 즉시 연결을 닫는다.

회귀 테스트는 수정 전 실패를 확인했다. 수정 후 종료 중 연결 금지, 지연 도구 중 수신 비용 정산, 지연 도구 중 즉시 예산 차단 3개 모두 통과했다. 실제 유료 Provider는 호출하지 않았다.
