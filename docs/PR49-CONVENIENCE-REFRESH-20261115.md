# PR #49 최신 main 통합 검증

2026-11-15 KST. 기준 main `13752e81`. 기존 PR의 고객 편의 기능을 최신 주문·결제·Live·푸시 흐름과 통합한다. 운영 배포·DB 변경·유료 API 호출은 제외한다.

## 충돌 해결

MenuPage의 일반 주문·분할 주문 콜백 의존성 두 곳에서 `testMenuMode`와 `ordersPaused`를 함께 유지했다. Live 팅커벨과 Voice Order, 기존 음성/직접 입력 폴백, 테스트 메뉴의 익명 현금 기본값, 주문 완료 화면·푸시·기존 결제 흐름을 보존한다. 통합 커밋 훅이 푸시 서비스/과거 결과 JSON의 줄바꿈도 재포맷했으며, 해당 diff를 검토해 암호화 옵션·증거 값의 기능 변경이 없음을 확인했다. 이 두 파일에 추가 수정은 하지 않는다.

## 기능별 확인

| 영역 | 검증 내용 |
| --- | --- |
| 메뉴 검색 | 이름·설명, 공백/대소문자 정규화, 검색 취소 |
| 알레르기 필터 | 매장이 등록한 항목만 노출, 제외 chip·복수 형식 정규화·고지 문구. 미등록 정보가 안전을 보증하지 않음 |
| ETA | 상품 조리시간·같은 매장 대기 주문·수량·추가 대기 반영, 범위 제한·조회 실패 기본값, 주문창 초기 표시·갱신 |
| 바쁨 모드 | 허용 대기/일시정지 값·서버 시각·자동 만료, 권한과 매장 범위, 새 주문 차단·화면 안내 |
| 셀프 취소 | 소유 주문 capability 필요, 주방 접수 전·미결제만 조건부 취소, 분할·PG 진행·결제 완료 거절, 현금 READY 정리 |
| 결제 경합 | 취소 주문의 PG 승인 진입 차단, 승인 응답 후 취소 상태면 DONE·장부 반영 없이 가짜 자동 취소 보상 |
| Live·기존 음성 | 명시 동의·서버 초안·고객 확인 후 장바구니, 오류 시 기존 음성/직접 입력, 다국어·캐릭터·OFF 기본값 유지 |

추가한 경합 테스트는 가짜 PG 응답을 Promise로 보류한 사이 취소 상태를 확정하고 응답을 재개한다. 장부 쓰기/결제 DONE 전환 없음과 보상 호출을 확인한다. 기존 현장 수납과 셀프 취소의 주문 행 잠금 및 조건부 갱신 경로도 검사한다. 이는 **모의 interleaving 검증**이며 실제 PostgreSQL 다중 트랜잭션 부하·실제 카드 승인 시험은 아니다.

## 적용 경계

`store_order_pace` 모델·migration 파일은 코드에 포함되지만 실제 DB에 적용하지 않는다. 미적용/조회 실패 시 기존 주문 접수·기본 ETA로 폴백하며, 바쁨 모드 저장 기능의 운영 사용 가능을 선언하지 않는다. 향후 적용은 승인형 migration·별도 운영 승인 대상이다.

모든 AI 활성화·유료 호출·매장·카메라/UI gate OFF, keep-warm 기본 OFF와 운영 배포 차단 유지. 실제 고객정보·카드·운영 Redis·실제 매장 설정을 사용하거나 변경하지 않는다. 신규 외부 게시/알림 발송도 수행하지 않는다.
