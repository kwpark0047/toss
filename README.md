# WeMarket (위마켓) - 스마트 QR 메뉴판 및 매장 관리 플랫폼

[![Web App](https://img.shields.io/badge/Web%20App-wemarket.vercel.app-blue?style=for-the-badge)](https://wemarket.vercel.app)

**WeMarket**은 소상공인을 위한 프리미엄 QR 메뉴판 및 통합 매장 관리 솔루션입니다. 고객은 앱 설치 없이 QR 코드 스캔만으로 메뉴 확인, 주문, 호출, 결제를 진행할 수 있으며, 관리자는 실시간 대시보드를 통해 매장 운영을 효율화할 수 있습니다.

## 🛠 주요 기술 스택 및 기능 (Tech Stack & Features)

### 1. 인프라 및 데이터베이스
- **Supabase (Database)**: 
  - PostgreSQL 기반의 고성능 데이터 저장소로 모든 매장, 메뉴, 주문 데이터를 관리합니다.
  - 실시간 데이터 구독(Real-time Subscription) 기능을 활용하여 주문 발생 시 관리자에게 즉각적인 알림을 전달합니다.
  - Row Level Security(RLS)를 적용하여 데이터 보안을 강화했습니다.
- **Render (Backend API & Automation)**:
  - Express 기반 백엔드 서버를 호스팅하며, 실시간 통신을 위한 Socket.io 서버 역할을 수행합니다.
  - **Cron Jobs**: 매월 오래된 로그(6개월 이상)를 자동 아카이빙하여 데이터베이스 성능을 최적화합니다.
  - **Auto-Scale**: 트래픽 증가에 따른 유연한 리소스 관리를 지원합니다.

### 2. 핵심 기능
- **프리미엄 QR 메뉴판**: 매장 아이덴티티에 맞춘 테마 컬러 및 폰트 설정, 고해상도 메뉴 이미지 노출.
- **스마트 주문 시스템**: 장바구니, 메뉴 옵션 선택, 실시간 주문 상태 추적(FCM 푸시 알림 연동).
- **고도화된 직원 호출**: 맥박 애니메이션 및 광택 효과가 적용된 고가시성 호출 버튼과 1:1 관리자 채팅 기능.
- **슈퍼관리자 대시보드**: 매장별 매출 분석, 실시간 상담 채팅, 공지사항 배너 관리.
- **통합 포인트 시스템**: 비회원(전화번호 기반) 적립 포인트와 회원 계정 간 자동 통합 로직 구현.
- **결제 고도화**: 토스페이먼츠 연동 및 1인 1메뉴 분할 결제 시 발생할 수 있는 잔액 오류 방지 로직 적용.

## 📈 개발 과정 (Development Process)

1. **요구사항 분석 및 설계**: 소상공인의 페인 포인트(높은 키오스크 도입 비용, 호출 벨의 한계)를 분석하여 모바일 웹 기반의 솔루션 기획.
2. **DB 스키마 구축**: Prisma를 활용하여 확장 가능한 PostgreSQL 데이터 구조 설계.
3. **백엔드 고도화 (Repository Pattern)**: 직접적인 DB 접근 대신 Repository 계층을 두어 비즈니스 로직의 응집도를 높이고 유지보수성 확보.
4. **프론트엔드 UI/UX 최적화**: Framer Motion을 활용한 부드러운 애니메이션과 Tailwind CSS 기반의 프리미엄 디자인 구현.
5. **실시간성 강화**: Socket.io와 Supabase Realtime을 결합하여 지연 없는 매장 환경 구축.
6. **안정성 및 리스크 관리**: 하드코딩된 API 제거, 로그 아카이빙 스크립트, 데이터 검증 로직 추가를 통한 시스템 안정화.

## 📖 사용법 (How to Use)

### [고객용]
1. 테이블에 부착된 **QR 코드**를 스캔합니다.
2. 브라우저에서 열린 메뉴판에서 원하는 메뉴를 선택하고 **장바구니**에 담습니다.
3. 주문하기를 누른 후, 알림을 받을 **전화번호**를 입력하거나 **FCM 알림**을 허용합니다.
4. 도움이 필요할 땐 우측 하단의 **직원 호출** 버튼을 통해 벨 호출이나 실시간 채팅을 요청할 수 있습니다.

### [관리자용]
1. `wemarket.vercel.app/admin`으로 접속하여 로그인합니다.
2. **매장 설정**에서 메뉴, 가격, 테마 컬러, 공지사항을 관리합니다.
3. **실시간 주문 현황** 탭에서 주문을 접수하고 조리 상태를 업데이트합니다.
4. **채팅/호출 목록**을 통해 고객의 요청에 즉각적으로 응대합니다.
